Which Tool Should I Choose?

Use Vocal Remover if you want vocal and instrumental outputs, or Karaoke Maker for a practice backing track. Audio Cutter creates a rehearsal clip, while Audio Looper, Speed and Pitch Changer and Metronome support repeated practice locally. BPM Tapper estimates tempo by tapping. Key Finder is an experimental local hint and should be checked by ear.
