# CleanStems Controlled Benchmark Audio

These audio samples are generated specifically for the CleanStems quality comparison page. They contain a synthesized lead-melody proxy and synthesized accompaniment, not a commercial recording or a real vocal performance.

- `reference-lead.wav`: known lead-melody reference.
- `reference-backing.wav`: known accompaniment reference.
- `test-mix.wav`: lossless mixed input.
- `test-mix-128k.mp3`: lossy input encoded from the same mix.
- Output files with `separated-` in their names are generated by the currently embedded public separation tool from the corresponding input.

The material may be used to reproduce the test and audition encoding-related differences. It is not intended to predict performance on every real song.
